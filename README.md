# Fundamentals of Data Science Lab

## About
This repository contains the practical experiments performed as part of the Fundamentals of Data Science course.

## Topics Covered
- Data Analysis and Visualization
- Data Preprocessing
- Statistical Analysis
- Exploratory Data Analysis (EDA)
- Machine Learning Algorithms
- Data Encryption and Decryption

## Tools Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Purpose
To learn and apply basic Data Science concepts through laboratory experiments.
